========
This document provides comprehensive details about the Razorpay payment gateway 
integration implemented in the Hema Pickles Next.js application. The integration 
includes a complete e-commerce solution with cart management, payment processing, 
and order tracking.

================================================================================
API ENDPOINTS
================================================================================

1. POST /api/payment/create-order
   Purpose: Create a new Razorpay order
   Input: { amount, currency, receipt, notes }
   Output: { success, order: { id, amount, currency, receipt, status } }

2. POST /api/payment/verify
   Purpose: Verify payment signature after successful payment
   Input: { razorpay_order_id, razorpay_payment_id, razorpay_signature, order_details }
   Output: { success, message, payment_id, order_id, order_details }

================================================================================
PAYMENT FLOW
================================================================================

1. USER ADDS ITEMS TO CART
   - User clicks "Add to Cart" on product pages
   - Items stored in CartContext and localStorage
   - Cart count updates in navbar

2. USER INITIATES CHECKOUT
   - User clicks cart button to open cart modal
   - User reviews items and clicks "Proceed to Checkout"
   - Checkout modal opens with customer form

3. PAYMENT PROCESSING
   - User fills mandatory customer information:
     * Name, Email, Phone (with validation)
     * Complete Address (Street, City, State, PIN Code, Country)
   - System validates all required fields
   - System creates Razorpay order via API
   - Razorpay checkout modal opens
   - User completes payment with Razorpay

4. PAYMENT VERIFICATION
   - Razorpay returns payment details
   - System verifies payment signature
   - Order created and stored locally
   - Success modal displayed

5. ORDER TRACKING
   - Order stored with tracking information
   - User can track order status
   - Order history maintained in localStorage

TROUBLESHOOTING
================================================================================

COMMON ISSUES:

1. Payment Gateway Not Loading
   - Check Razorpay script loading
   - Verify API keys are correct
   - Check network connectivity

2. Payment Verification Failing
   - Verify webhook signature calculation
   - Check server-side key configuration
   - Validate payment response format

3. Cart Not Persisting
   - Check localStorage availability
   - Verify CartContext provider wrapping
   - Check for JavaScript errors

4. Styling Issues
   - Verify SCSS module imports
   - Check responsive breakpoints
   - Validate CSS class names
